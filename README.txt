FOODIE TELEGRAM MINI APP — DEMO

This is a static frontend prototype only.
- Restaurant/food data is sample data in app.js.
- Search, categories, add/remove cart and checkout preview work locally.
- Checkout is DEMO ONLY. It does not place a Swiggy order.
- No database or backend is included.
- Telegram Web App JS is loaded from Telegram's official CDN.

DEPLOY:
1. Upload this ZIP to Cloudflare Pages using Direct Upload.
2. Copy the HTTPS *.pages.dev URL.
3. In @BotFather, use /mybots > choose your bot > Bot Settings > Configure Mini App > Enable Mini App (or Main Mini App) and set the URL.
4. Alternatively, configure the bot's Menu Button with /setmenubutton and the same HTTPS URL.
5. Open the bot in Telegram and test.

To edit the sample menu, change the foods array in app.js.
